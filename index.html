Working with MongoDB using Shell Commands

Creating databases and collections, inserting, retrieving, updating and deleting documents, and querying data with mongosh.

1. Student Database Management

Student Database Management (database: CollegeDB, collection: students)

Setup: create database, collection and insert 5 students

db.students.drop();                       // start clean so the script can be re-run
db.createCollection("students");
db.students.insertMany([
  { rollNo: 101, name: "Arun",  department: "CSE", age: 20, mark: 85 },
  { rollNo: 102, name: "Priya", department: "IT",  age: 21, mark: 92 },
  { rollNo: 103, name: "Kumar", department: "CSE", age: 19, mark: 78 },
  { rollNo: 104, name: "Divya", department: "ECE", age: 20, mark: 88 },
  { rollNo: 105, name: "Ravi",  department: "CSE", age: 22, mark: 67 }
]);

a. Display all student records

printjson(db.students.find().toArray());

b. Retrieve a student using the roll number

printjson(db.students.findOne({ rollNo: 102 }));

c. Students who scored more than 80 marks

printjson(db.students.find({ mark: { $gt: 80 } }).toArray());

d. Update the marks of a particular student

db.students.updateOne({ rollNo: 101 }, { $set: { mark: 90 } });
printjson(db.students.findOne({ rollNo: 101 }));    // verify

e. Delete a student record using the roll number

db.students.deleteOne({ rollNo: 105 });
printjson(db.students.find().toArray());            // verify

Run: mongosh --file scripts/01_student_database.js

2. Employee Database

Employee Database (database: EmployeeDB, collection: employees)

Setup: create database, collection and insert 5 employees

db.employees.drop();
db.createCollection("employees");
db.employees.insertMany([
  { empId: 1, name: "Anita",  department: "HR",      salary: 35000, experience: 3 },
  { empId: 2, name: "Bala",   department: "IT",      salary: 52000, experience: 5 },
  { empId: 3, name: "Charan", department: "IT",      salary: 45000, experience: 4 },
  { empId: 4, name: "Deepa",  department: "Finance", salary: 40000, experience: 6 },
  { empId: 5, name: "Eswar",  department: "IT",      salary: 60000, experience: 8 }
]);

a. Display all employees

printjson(db.employees.find().toArray());

b. Employees earning more than Rs. 40,000

printjson(db.employees.find({ salary: { $gt: 40000 } }).toArray());

c. Update the salary of an employee

db.employees.updateOne({ empId: 1 }, { $set: { salary: 38000 } });
printjson(db.employees.findOne({ empId: 1 }));      // verify

d. Employees in descending order of salary

printjson(db.employees.find().sort({ salary: -1 }).toArray());

e. Count employees in a particular department (IT)

print(db.employees.countDocuments({ department: "IT" }));

Run: mongosh --file scripts/02_employee_database.js

3. Product Database

Product Database (database: ProductDB, collection: products)

Setup: create database, collection and insert products

db.products.drop();
db.createCollection("products");
db.products.insertMany([
  { productId: 1, name: "Keyboard",   category: "Electronics", price: 1200,  stock: 25 },
  { productId: 2, name: "Mouse",      category: "Electronics", price: 600,   stock: 40 },
  { productId: 3, name: "Notebook",   category: "Stationery",  price: 80,    stock: 0  },
  { productId: 4, name: "Headphones", category: "Electronics", price: 2500,  stock: 15 },
  { productId: 5, name: "Backpack",   category: "Accessories", price: 1800,  stock: 10 },
  { productId: 6, name: "Pen Pack",   category: "Stationery",  price: 120,   stock: 0  },
  { productId: 7, name: "Monitor",    category: "Electronics", price: 9500,  stock: 5  }
]);

a. Products belonging to a specific category

printjson(db.products.find({ category: "Electronics" }).toArray());

b. Products priced between Rs. 500 and Rs. 2,000

printjson(db.products.find({ price: { $gte: 500, $lte: 2000 } }).toArray());

c. Increase the stock quantity of a product (+20)

db.products.updateOne({ productId: 2 }, { $inc: { stock: 20 } });
printjson(db.products.findOne({ productId: 2 }));   // verify

d. Delete products whose stock quantity is zero

db.products.deleteMany({ stock: 0 });
printjson(db.products.find().toArray());            // verify

e. Display the five most expensive products

printjson(db.products.find().sort({ price: -1 }).limit(5).toArray());

Run: mongosh --file scripts/03_product_database.js

5. Query Operations

Query Operations on the students collection (CollegeDB)

Setup: reset the students collection

db.students.drop();
db.students.insertMany([
  { rollNo: 101, name: "Arun",  department: "CSE", age: 20, mark: 85 },
  { rollNo: 102, name: "Priya", department: "IT",  age: 21, mark: 92 },
  { rollNo: 103, name: "Kumar", department: "CSE", age: 19, mark: 78 },
  { rollNo: 104, name: "Divya", department: "ECE", age: 20, mark: 88 },
  { rollNo: 105, name: "Ravi",  department: "CSE", age: 22, mark: 67 }
]);

a. Marks greater than or equal to 75

printjson(db.students.find({ mark: { $gte: 75 } }).toArray());

b. Age less than 21

printjson(db.students.find({ age: { $lt: 21 } }).toArray());

c. Students belonging to either CSE or IT

printjson(db.students.find({ department: { $in: ["CSE", "IT"] } }).toArray());

d. Top three students based on marks

printjson(db.students.find().sort({ mark: -1 }).limit(3).toArray());

e. Update multiple records using updateMany() (+5 marks for CSE)

db.students.updateMany({ department: "CSE" }, { $inc: { mark: 5 } });
printjson(db.students.find({ department: "CSE" }).toArray());   // verify

Run: mongosh --file scripts/05_query_operations.js
