# Ex. No. 9: Working with MongoDB using Shell Commands

## Run the scripts
1. Install MongoDB Community Server and mongosh, and make sure the server is running (`mongod`).
2. In a terminal, from this folder:

   mongosh --file scripts/01_student_database.js
   mongosh --file scripts/02_employee_database.js
   mongosh --file scripts/03_product_database.js
   mongosh --file scripts/04_library_database.js
   mongosh --file scripts/05_query_operations.js

Each script drops and recreates its own collection, so it can be run again safely.

## Or type the commands by hand (what the lab sheet shows)
    mongosh
    use CollegeDB
    db.students.find()
Copy any block from index.html and paste it into mongosh.

## Notes
- `.pretty()` is not needed in mongosh; output is already formatted.
- Scripts print with printjson(...) because `mongosh --file` does not auto-print query results.
- index.html is the web page for GitHub Pages (upload index.html to the repo root). It is generated by `node build.mjs`.
